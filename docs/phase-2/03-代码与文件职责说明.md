# 第 2 阶段代码与文件职责说明

本文帮助产品、术语和研发人员定位第二阶段各部分代码。

## 1. 领域模型

| 文件/目录 | 职责 |
|---|---|
| `Domain/Terminology/Concept.cs` | 概念聚合；管理三语术语、定义、来源关联和公开版本状态 |
| `Domain/Terminology/Source.cs` | 来源元数据、许可证、URL/标识及启停状态 |
| `Domain/Terminology/ConceptSource.cs` | 概念与来源之间的证据类型和页码/章节定位 |
| `Domain/Workflow/ConceptRevisionSnapshot.cs` | 定义不可变修订快照；执行三语、定义和来源完整性检查 |
| `Domain/Workflow/ConceptRevision.cs` | 草稿、提交、批准、退回、发布状态机与 `revisionToken` 并发控制 |
| `Domain/Workflow/ReviewRecord.cs` | 追加式保存每次审核动作、操作人、意见和时间 |
| `Domain/Workflow/OutboxMessage.cs` | 在同一事务记录发布事件，供后续索引同步可靠消费 |
| `Domain/Importing/ImportJob.cs` | 导入任务状态、行数统计和错误集合 |
| `Domain/Importing/ImportRowError.cs` | 单个 CSV 行/字段的结构化错误 |

## 2. API 契约与权限

| 文件/目录 | 职责 |
|---|---|
| `Application.Contracts/Terminology` | 术语编辑、修订审核输入输出 DTO 和服务接口 |
| `Application.Contracts/Sources` | 来源维护 DTO 和服务接口 |
| `Application.Contracts/Importing` | CSV 内容输入、任务结果和错误 DTO |
| `Application.Contracts/Permissions` | Concepts、Sources、Imports 权限树 |

DTO 是 Web/UniApp 与后端之间的稳定边界；客户端不应直接依赖 EF 实体。

## 3. 应用服务

| 文件 | 职责 |
|---|---|
| `Application/Terminology/TerminologyAdminAppService.cs` | 编排创建、修改、提交、审核、发布；校验领域和来源；写审核记录及 Outbox |
| `Application/Sources/SourceAppService.cs` | 来源查询、创建、修改和启停 |
| `Application/Importing/CsvTableParser.cs` | RFC 4180 风格 CSV 基础解析，支持引号、逗号和换行 |
| `Application/Importing/ImportAppService.cs` | 校验模板与每行数据，复用来源，创建概念草稿和错误报告 |

## 4. HTTP 控制器

| 文件 | 职责 |
|---|---|
| `HttpApi/Controllers/AdminConceptsController.cs` | 概念读取、创建和发起新修订 |
| `HttpApi/Controllers/AdminRevisionsController.cs` | 修订修改、提交、批准、退回和发布 |
| `HttpApi/Controllers/SourcesController.cs` | 来源管理 HTTP 路由与权限保护 |
| `HttpApi/Controllers/ImportJobsController.cs` | CSV 文件上传、大小/扩展名边界和任务查询 |
| `HttpApi.Host/wwwroot/admin/index.html` | 管理端三个页面的语义结构与连接、来源弹窗 |
| `HttpApi.Host/wwwroot/admin/styles.css` | 桌面与窄屏布局、表单、差异表和导入结果视觉样式 |
| `HttpApi.Host/wwwroot/admin/app.js` | 页面导航、表单状态、审核动作、上传和错误报告交互 |
| `HttpApi.Host/wwwroot/admin/api.js` | Bearer 令牌内存管理与管理 API 请求封装 |
| `HttpApi.Host/wwwroot/admin/diff.js` | 将已发布版本与待审核修订转为逐字段差异 |
| `HttpApi.Host/wwwroot/admin/template-v1.csv` | 管理端可直接下载的 CSV 示例模板 |

控制器只处理 HTTP 关注点，业务规则集中在领域模型与应用服务中。

## 6. 修改功能时从哪里开始

- 改审核规则：先改 `ConceptRevision`/`ConceptRevisionSnapshot`，再补领域测试。
- 增加术语字段：同步修改快照、DTO、映射、DbContext 和迁移。
- 增加导入列：修改 `ImportAppService` 的表头及行映射，同时更新模板和本文档。
- 接 Web 或 UniApp：以 `Application.Contracts` DTO 和 OpenAPI 为准，不直接复制领域实体。
- 接搜索索引：消费 `td_outbox_messages`，成功后调用 `MarkProcessed` 对应的后台处理逻辑。
