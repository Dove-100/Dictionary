## 2. 产品参考分析

网易有道官方产品资料展示了多语查词、例句、发音、专业词汇学科标注、单词本以及词组和同近义词等能力。本项目采用其中符合用户心智的通用交互模式，同时结合专业术语系统的特性做以下取舍：

| 通用模式 | 本项目采用方式 | 项目差异 |
|---|---|---|
| 大搜索框与语言识别 | 首页和详情页均保留可见搜索入口 | 汉西英三语概念检索，支持领域过滤 |
| 词头与发音 | 词头顶部展示语言、音标/拼音、真人或合成发音 | 发音来源和类型可追溯 |
| 分词性/分释义 | 按义项编号、领域和使用场景分组 | 每个义项对应独立概念代码和版本 |
| 例句 | 例句紧随所属义项展示 | 三语例句可对齐，并记录许可与来源 |
| 词组、同近义词、相关词 | 按当前义项关联展示 | 禁止跨义项错误混排 |
| 单词本/收藏 | 登录用户可收藏概念或指定义项 | 多端同步并支持分类扩展 |
| 专业学科标注 | 显示领域路径和次领域 | 领域可参与权限、检索和审核 |

参考来源：[网易有道词典首页](https://dict.youdao.com/home)、[有道词典特色功能](https://cidian.youdao.com/features/)、[词组与同近义词帮助](https://cidian.youdao.com/5.0/help/deskdict5beta/description/10.html)。上述页面仅用于功能调研，项目不得抓取或复制其受保护内容。

## 3. 多义词数据规则

```text
查询词形/词头
  ├─ 义项 1 → Concept A → 三语术语、定义、例句、来源、关系
  ├─ 义项 2 → Concept B → 三语术语、定义、例句、来源、关系
  └─ 义项 3 → Concept C → 三语术语、定义、例句、来源、关系
```

前端义项是聚合展示，数据库事实来源仍是独立概念。以西班牙语 `modelo` 为例：

| 义项 | 场景 | 中文 | Español | English |
|---|---|---|---|---|
| 1 | 科研/计算 | 模型 | modelo | model |
| 2 | 工业产品 | 型号 | modelo | model / product model |
| 3 | 文化创意/时尚 | 模特 | modelo | model |

三种意义不得共享同一段定义，也不能因为西班牙语和英语词形相同而合并概念。

## 5. 后续测试要求

1. 黄金查询集新增至少 50 条多义词案例，覆盖三种源语言。
2. 每个案例记录查询词、预期义项集合、各义项概念代码和默认排序。
3. 搜索测试同时检查“没有漏掉义项”和“没有把义项定义混合”。
4. 详情页端到端测试验证例句、来源和相关词均属于当前义项。
5. 专家复核时逐义项签署，不能只对词头整体标记 Reviewed。

## 6. 多义词黄金查询增补结果

已在黄金查询集 V0.2 中完成本项要求：

- 新增 `PolysemyCases` 工作表，共 72 条多义词检索与义项隔离测试，汉语、西班牙语、英语各 24 条。

- 新增测试和义项均保持 `Draft` 状态，须由术语专家、领域专家和测试负责人逐义项签字后才能转为 `Reviewed`。
