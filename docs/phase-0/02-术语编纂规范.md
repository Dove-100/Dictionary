# 汉西英三语术语编纂规范

> 版本：V1.0  
> 适用对象：术语编辑、审核专家、数据管理员、研发和测试人员

## 1. 规范依据

本规范以概念导向术语工作为基础，参考以下公开标准信息：

- [ISO 704:2022](https://www.iso.org/standard/79077.html)：术语工作的原则与方法，说明对象、概念、定义和指称之间的关系。
- [ISO 1087:2019](https://www.iso.org/standard/62330.html)：术语工作与术语学的基础词汇。
- [ISO 30042:2019](https://www.iso.org/standard/62510.html)：TBX 术语资源交换元模型。
- [SKOS Reference](https://www.w3.org/TR/skos-reference/)：概念、首选标签、备选标签和概念关系的交换参考。
- [RFC 5646](https://www.rfc-editor.org/info/rfc5646/)：语言标签结构。
- [Unicode UAX #15](https://www.unicode.org/reports/tr15/)：Unicode 规范化形式。

本规范不复制付费标准正文；项目实施时如需正式符合性声明，应由项目方取得相应标准文本并完成逐条核对。

## 2. 基本术语

| 名称 | 项目定义 |
|---|---|
| 概念 Concept | 由一组特征构成的知识单位，是词典条目的核心标识 |
| 术语 Term | 在特定语言和专业领域中指称概念的词或词组 |
| 首选术语 Preferred term | 某语言、地区和使用场景中推荐使用的规范表达 |
| 允许术语 Admitted term | 可以使用但不是首选的表达 |
| 弃用术语 Deprecated term | 不推荐继续使用、但为检索和迁移保留的表达 |
| 定义 Definition | 用已知概念和区别特征界定目标概念的陈述 |
| 概念关系 | 概念之间的上下位、整体部分、相关等关系 |
| 来源 Source | 支持术语、定义、例句或关系的可追溯证据 |
| 修订 Revision | 对概念聚合内容的一次有版本、责任人和审核结果的变更 |

## 3. 条目组织原则

1. 一个概念建立一个概念记录，不因语言数量拆成三个词条。
2. 一个术语只表达它在该概念下的用法；同形异义必须建立不同概念。
3. 三种语言不是逐词强制对称。不存在完全等值术语时，应说明范围差异，不得强造译词。
4. 定义优先描述概念本质和区别特征，不使用目标术语自身作循环定义。
5. 规范性判断必须说明领域、地区、机构或标准范围。
6. 所有正式发布内容必须可追溯到来源和审核责任。

## 4. 概念记录字段

| 字段 | 必填 | 规则 |
|---|---|---|
| ConceptCode | 是 | 稳定、不可复用，格式 `领域码-六位序号`，如 `IT-000001` |
| DomainCode | 是 | 取自有效领域树；可附加多个次领域 |
| Status | 是 | Draft、InReview、Rejected、Approved、Published、Deprecated |
| ReliabilityCode | 是 | Unverified、CorpusSupported、ExpertReviewed、Authoritative |
| Definition | 是 | 已发布时至少一条；三语定义为质量目标 |
| Source | 是 | 已发布时至少一项可定位来源 |
| Relations | 否 | 使用受控关系类型，方向明确 |
| Notes | 否 | 使用范围、歧义、地区和审校说明，不承载正式定义 |

## 5. 术语字段与规则

### 5.1 通用字段

| 字段 | 必填 | 示例 |
|---|---|---|
| LanguageTag | 是 | `zh-Hans`、`es`、`es-ES`、`en`、`en-US` |
| Text | 是 | `人工智能` / `inteligencia artificial` / `artificial intelligence` |
| TermType | 是 | Preferred、Admitted、Deprecated、Abbreviation、Symbol、Variant |
| PartOfSpeech | 是 | Noun、Verb、Adjective、Adverb、Phrase、Other |
| Region | 否 | ES、MX、AR、US、GB 等 |
| Gender | 西语名词建议必填 | masculine、feminine、common、notApplicable |
| Number | 需要时填写 | singular、plural、invariable |
| UsageLabel | 否 | formal、informal、technical、historical、trademark |
| Pronunciation | 否 | IPA、拼音或审核音频 |

### 5.2 中文

- 原文使用规范简体中文；繁体形式需要时作为 `Variant` 记录，并使用对应语言/脚本标签。
- 不在首选术语中加入解释性括号，除非括号是正式名称组成部分。
- 字母缩略语单独作为 Abbreviation，不替代中文首选术语。
- 拼音作为检索辅助与发音字段，不能作为中文术语正文。

### 5.3 西班牙语

- 保留重音符号、分音符和 `ñ`，首选术语不得使用去重音形式。
- 名词记录语法性别；通常使用单数词典形式，惯用复数除外。
- 地区差异使用地区标签，不把所有变体强行合并为一个首选词。
- 缩略语的大小写和标点遵循权威来源；全称与缩略语建立同概念关联。
- 搜索可以容忍缺失重音，但展示和正式数据必须保留正确拼写。

### 5.4 英语

- 普通术语使用词典形式；可数名词原则上用单数，惯用复数除外。
- 英美差异用地区标签管理，不能仅在备注中隐藏。
- 专名、标准名称和缩略语保留规定大小写。
- 连字符差异可作为 Variant；首选形式依领域权威来源确定。

## 6. 定义编写规则

1. 定义应说明上位概念和区别特征，保持一个句法中心。
2. 不以“是指”“所谓”等无信息开头堆砌，不加入宣传或评价性语言。
3. 不使用待定义术语或其简单变形形成循环定义。
4. 定义中的其他专业概念应尽量可链接到词典概念。
5. 引用定义必须标记引用范围和来源；改写定义标记为改写并保留来源。
6. 不同语言定义应概念等值，不要求逐字互译。
7. 一个概念存在学派差异或法规差异时，分别记录定义及适用范围。

## 7. 例句规则

- 例句用于展示真实搭配和语域，不重复定义。
- 优先使用有许可的自编例句、公共领域或明确授权语料。
- 三语例句可用 TranslationGroupId 对齐；译文应自然，不强求词序一致。
- 每条例句记录语言、来源、许可和必要的上下文。
- 不收录个人敏感信息、歧视性内容或无法证明使用权的长篇文本。

## 8. 概念关系

| 关系 | 方向 | 规则 |
|---|---|---|
| Broader / Narrower | 有向互逆 | 表示类属上下位，禁止循环 |
| PartOf / HasPart | 有向互逆 | 表示整体部分，禁止循环 |
| Related | 对称 | 有明确专业关联但非上下位 |
| Equivalent | 对称 | 仅用于不同概念方案的等值映射，不代替同概念多语术语 |
| Antonym | 对称 | 适用于确有反义关系的概念 |
| Causes | 有向 | 需要可靠来源，不用于主观因果 |
| UsedFor | 有向 | 表示典型用途，避免泛化 |

## 9. 来源与证据

### 9.1 来源优先级

1. 法律法规、国际/国家/行业标准、权威机构术语库。
2. 领域学会、政府和研究机构出版物。
3. 同行评议论文、专业教材和正式技术文档。
4. 经验证的专业语料库。
5. 一般网页仅作为候选线索，不单独支撑 Authoritative 等级。

### 9.2 最低书目信息

标题、作者/机构、出版者、年份、标识符或 URL、访问日期、页码/条款（适用时）、许可证或使用依据。网页失效不能导致来源完全不可定位。

## 10. 文本与语言技术规范

- 所有文本以 UTF-8 交换，数据库原文保存为 Unicode NFC。
- 不对展示原文执行 NFKC 覆盖；兼容折叠仅可生成独立检索字段。
- 语言标签遵循 BCP 47/RFC 5646；禁止自造无法解析的语言代码。
- 前后空白、连续普通空格可在入库时规范化；有语义的标点和重音不得删除。
- 检索规范化必须可重复、可测试、可记录版本。

## 11. 质量等级

| 等级 | 最低条件 | 发布建议 |
|---|---|---|
| Unverified | 自动导入或机器候选，尚未人工核对 | 不公开或明确标记候选 |
| CorpusSupported | 有语料证据，结构校验通过 | 可进入专家审核 |
| ExpertReviewed | 至少一名领域/语言专家审核 | 可正式发布 |
| Authoritative | 有权威标准/机构来源并通过高级审核 | 优先展示 |

## 12. 审核清单

- [ ] 概念边界清楚，无同形异义误合并。
- [ ] 中西英首选术语语义范围一致或差异已说明。
- [ ] 语言标签、词性、地区、性别和术语类型正确。
- [ ] 定义无循环、无宣传性、无明显事实错误。
- [ ] 例句自然且许可清楚。
- [ ] 来源可定位，可靠等级与证据相符。
- [ ] 概念关系类型、方向和目标正确，无自指或循环。
- [ ] 弃用词指向推荐用语。
- [ ] 变更摘要准确，编辑与审核人员分离。

## 13. 交换映射

| 项目字段 | TBX/SKOS 对应意图 |
|---|---|
| Concept | TBX termEntry / `skos:Concept` |
| Preferred term | language section term / `skos:prefLabel` |
| Admitted/Variant | term / `skos:altLabel` |
| Deprecated term | administrative status + term / `skos:hiddenLabel` 仅作检索映射参考 |
| Definition | descriptive field / `skos:definition` |
| Broader/Narrower | relation / `skos:broader`、`skos:narrower` |
| Related | relation / `skos:related` |
| Source | bibliographic/administrative metadata / `dcterms:source` |

具体导入导出映射需在第 1～2 阶段形成机器可执行的数据字典和示例文件。
