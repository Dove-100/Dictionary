# 开发环境与运行手册

## 构建与测试

```powershell
$dotnetExe = Join-Path $PWD '.tools/dotnet/dotnet.exe'
& $dotnetExe restore TriDict.sln
& $dotnetExe build TriDict.sln -c Release --no-restore
& $dotnetExe test TriDict.sln -c Release --no-build
```

## Docker 环境

```powershell
Copy-Item .env.example .env
docker compose -f deploy/docker/compose.yml up --build
```

默认启动 PostgreSQL、Redis、迁移程序和 API。OpenSearch 预留到检索阶段，按需启动：

```powershell
docker compose -f deploy/docker/compose.yml --profile search up --build
```

## 独立执行迁移

```powershell
$env:TRIDICT_CONNECTION_STRING = 'Host=localhost;Port=5432;Database=tridict;Username=tridict;Password=tridict_dev'
& .tools/dotnet/dotnet.exe run --project src/TriDict.DbMigrator
```

迁移程序会执行 EF Core 迁移并写入 ECON、IT、RES、CUL 四个一级领域。生产密码必须通过秘密管理服务注入，不得提交到仓库。

## 配置覆盖

ASP.NET Core 使用双下划线映射环境变量，例如：

- `ConnectionStrings__Default`
- `Authentication__Authority`
- `Authentication__Audience`
- `Authentication__RequireHttpsMetadata`

开发环境允许关闭身份服务 HTTPS 元数据验证；测试和生产必须启用。
