# 汉西英三语词典领域分类体系

> 版本：V1.0  
> 原则：稳定代码、可扩展层级、多语名称、概念可多领域归属

## 1. 编码规则

- 一级领域使用 2～4 位大写字母：`ECON`、`IT`、`RES`、`CUL`。
- 二级领域使用 `一级码.两位序号`，例如 `ECON.01`。
- 三级领域按需使用 `一级码.二级序号.二级序号`。
- 代码一经发布不得复用；重命名只改名称，不改代码。
- 概念有一个主领域，可关联多个次领域。

## 3. 归类规则

1. 以概念的主要专业使用场景确定主领域，而非词语日常含义。
2. 一个概念跨领域使用时，保留一个主领域并增加次领域，不复制概念。
3. 领域只能描述知识范围，不用于表达语言、地区、用户权限或内容状态。
4. 新增二级领域前先验证现有节点是否可承载，并评估至少 20 个潜在概念。
5. 领域移动需评估搜索筛选、权限、统计和永久链接，不直接改代码。
6. 同层节点尽量互斥，但允许专业知识客观交叉；交叉通过次领域表达。

## 5. 治理流程

领域新增、合并、停用依次经过提案、影响分析、术语负责人审核、数据迁移方案、发布。停用节点保留代码和重定向，不物理删除已有引用。每次变更记录中西英名称、定义、范围说明、示例概念、提出人和生效版本。

## 6. 待专家确认

- “科研教育”是否拆为科研与教育两个一级领域。
- 医学术语是否属于首期范围；若数据量较大，应独立一级领域。
- 经贸中的商法术语是否需要法域标签和独立审核角色。
- 西班牙语领域名称采用通用表达还是指定西班牙/拉美地区偏好。
