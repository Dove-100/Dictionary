## 阶段边界

本阶段建立可扩展底座，不在 API 启动时自动迁移数据库。完整身份中心、管理端编辑审核、OpenSearch 排序和黄金查询自动回归属于后续阶段；现有 JWT/OIDC 配置是统一鉴权接入边界。

## 进入第 2 阶段的条件

1. 产品、术语和技术负责人确认当前核心实体字段。
2. 确认身份服务 Authority、Audience 与角色/权限映射。
3. 取得至少 100 条具备许可证信息的原始术语记录并完成字段剖析。
4. 使用 PostgreSQL 实例执行首个迁移与回退演练。
