## 本阶段冻结的决策

1. 采用概念导向数据模型，一个概念关联中文、西班牙语、英语的多个术语表达。
2. V1.0 一级领域为经贸、信息技术、科研教育、文化交流。
3. 中文基线为 `zh-Hans`，西班牙语基线为 `es`，允许 `es-ES`、`es-419` 等地区标记；英语基线为 `en`，允许地区标记。
4. 已发布概念原则上必须具备三语首选术语、至少一条定义和一项可追溯来源。
5. 搜索首期实现精确、变体、前缀、模糊、定义全文和语音转文本查询。
6. 机器翻译和自动抽取结果只能作为候选，不得自动发布。
7. 内容发布执行编辑与审核分离，审核者不能审核本人提交的修订。
8. 原始文本使用 Unicode NFC 保存，检索规范化字段与展示原文分离。
9. 公开词典页采用成熟在线词典的搜索优先、词头信息、发音、分义项、例句、相关词和收藏模式，但不复制第三方品牌、素材、数据或具体视觉表达。
10. 同一词形存在多个意义时，每个意义对应独立概念，并按领域与使用场景形成独立义项；查询页可将多个义项聚合展示。

## 进入第 1 阶段的条件

- 产品负责人确认 V1.0 范围和明确排除项。
- 术语负责人确认编纂规范、领域树和首选术语规则。
- 技术负责人确认需求编号、数据字段和外部服务边界。
- 测试负责人接受黄金查询集的字段结构和评价方法。
- 待确认参数可以保留默认值进入开发，但必须在数据库冻结前关闭。

## 使用方式

评审顺序建议为需求规格、编纂规范、领域树、页面原型、黄金查询集、追踪矩阵。评审意见统一记录在阶段评审记录中，不直接修改已通过的基线；变更应新增版本并记录原因、提出人和影响范围。
