> 阶段名称：术语编辑与审核发布闭环

## 阶段目标

把第 1 阶段的只读术语查询底座扩展为可治理的数据生产系统，形成“来源建档 → 草稿编辑/批量导入 → 提交 → 审核 → 发布 → 公开查询”的完整闭环。多义词仍以独立概念和明确场景保存，修订快照不会合并不同义项。

## 阶段边界

- 本阶段提供 CSV 1.0 模板。XLSX、TBX 解析器沿用相同导入任务与校验模型，列入后续适配，不会绕过审核直接发布。
- 管理端页面和 UniApp 编辑界面尚未实现，本阶段 API 已为其提供稳定契约。
- 发布事件已可靠写入 Outbox；搜索索引消费者将在检索增强阶段接入。
- 数据库迁移已生成，但本地未配置真实 PostgreSQL 凭据时只做迁移结构与编译验证。

## 验收入口

1. 创建或选择有效来源。
2. 创建包含中、西、英首选术语、至少一个场景定义和来源的草稿。
3. 使用返回的 `revisionToken` 提交审核。
4. 用不同用户批准修订，再由发布权限用户发布。
5. 确认公开查询只返回发布后的版本。
6. 上传模板 CSV，确认有效行成为草稿、错误行返回行号和字段。
