# 管理端页面使用说明

## 打开页面

启动 API 宿主后访问 `http://localhost:8080/admin/`。若使用本地 `dotnet run`，端口以启动日志为准。页面直接由 ASP.NET Core 宿主提供，不需要 Node 构建步骤。

点击右上角“连接 API”，输入项目身份服务签发的 Bearer access token。令牌只放在当前页面内存中，刷新页面后需要重新输入。权限仍由后端 `TriDict.Concepts`、`TriDict.Sources` 和 `TriDict.Imports` 等权限点判断。未配置身份服务或数据库时，可检查页面布局和字段，但不能执行真实保存、审核或导入。

## 术语编辑

1. 选择现有概念或点击“新建概念”。
2. 填写编码、领域、修订说明；在中文、西班牙语、英语标签中录入首选术语。
3. 分别填写定义和场景标签。多义词的不同意义需用独立概念编码，明确使用场景。
4. 关联来源；若来源尚未建档，可从“新建来源”弹窗创建。
5. 保存草稿或直接提交审核。页面会提示缺少的三语首选术语、定义和来源。
6. 已发布词条点击“创建新修订”后编辑，旧版本在新修订发布前继续对外展示。

编辑会使用 `revisionToken` 做并发控制。若服务端返回 HTTP 409，请刷新并检查其他人的修改后再继续。

## 审核差异

“待审核”和“已批准”两个队列按最新修订状态筛选。选择一条修订后，右侧按领域、可靠等级、三语术语、定义场景和来源证据逐项比较当前公开版本与待处理快照。首次发布以空白基线比较。

审核人可批准或退回，退回必须填写原因；发布权限用户可发布已批准修订。服务端禁止提交人审核自己的修订。

## 导入结果

点击“下载 CSV 模板”查看列名与样例；上传 UTF-8 `.csv` 文件后，页面展示总行数、已创建草稿数和错误行数。任务历史可查看以前的结果，并下载包含行号、字段、错误码、说明的错误明细 CSV。

导入有效行只会成为草稿，仍须在术语编辑与审核流程中逐条发布。文件限制为 2 MB、5000 个数据行。

## 页面文件

页面入口位于 `src/TriDict.HttpApi.Host/wwwroot/admin/index.html`。样式在 `styles.css`，页面逻辑在 `app.js`，请求封装在 `api.js`，审核差异计算在 `diff.js`。本阶段无外部前端运行时依赖。
