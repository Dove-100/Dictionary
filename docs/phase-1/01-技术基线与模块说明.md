# 技术基线与模块说明

## 固定版本

| 组件 | 版本 | 说明 |
|---|---:|---|
| .NET SDK | 10.0.401 | `global.json` 固定，LTS |
| ABP Framework | 10.6.0 | 中央包管理固定 |
| EF Core | 10.0.9 | 设计工具与运行时同主版本 |
| PostgreSQL | 18 | 本地容器默认版本 |

所有 NuGet 版本集中维护在 `Directory.Packages.props`，项目文件不得单独写版本号。

## 依赖方向

```text
Domain.Shared
  ↑
Domain ← EntityFrameworkCore
  ↑             ↑
Application.Contracts ← HttpApi
  ↑
Application
  ↑
HttpApi.Host
```

`Application` 只依赖领域仓储接口，不直接依赖 EF Core。`HttpApi.Host` 是组合根，负责数据库提供程序、鉴权、CORS、健康检查和端点管线。

## 已落地的领域约束

- 同一词形的不同意义必须使用不同 `Concept` 和 `ConceptCode`。
- 一个概念的同一语言只能有一个首选术语。
- 进入审核至少需要汉语、西班牙语、英语三个首选术语和一条定义。
- 只有 `InReview` 可以批准，只有 `Approved` 可以发布。
- `UsageContext` 与 `SenseOrder` 存在于术语层，用于公开端义项聚合和稳定排序，不参与概念身份判断。
- 公开查询只返回 `Published` 概念，定义与三语术语始终从当前概念内部映射，防止串义。

## 数据库策略

PostgreSQL 是事实来源。首个迁移包含 `td_domains`、`td_concepts`、`td_terms` 和 `td_definitions`，并建立概念代码、领域状态、规范化词形和语言首选词唯一性索引。API 不自动迁移；部署流程必须先运行 `TriDict.DbMigrator`。
