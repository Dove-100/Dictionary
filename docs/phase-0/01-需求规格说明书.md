# 汉西英三语在线词典系统需求规格说明书

> 版本：V1.0  
> 状态：第 0 阶段评审基线

## 1. 产品目标

系统面向需要汉语、西班牙语和英语专业术语互查的学习者、翻译人员、经贸与科研从业者，以及术语编辑专家。产品以可追溯的规范术语数据为核心，以智能检索和语音查询降低查询成本，以审核、版本和质量流程保证长期可信度。

## 2. 成功指标

| 编号 | 指标 | V1.0 目标 | 测量方式 |
|---|---|---:|---|
| KPI-01 | 黄金查询集 Top 1 准确率 | ≥ 85% | 按发布版本自动回归 |
| KPI-02 | 黄金查询集 Top 5 召回率 | ≥ 95% | 按语言、领域、匹配类型分组 |
| KPI-03 | 精确搜索 P95 | ≤ 500 ms | 服务端监控，不含客户端网络 |
| KPI-04 | 搜索建议 P95 | ≤ 200 ms | 服务端监控 |
| KPI-05 | 已发布概念三语完整率 | ≥ 98% | 数据质量任务每日统计 |
| KPI-06 | 已发布概念来源覆盖率 | 100% | 发布前强校验 |
| KPI-07 | 审核轨迹完整率 | 100% | 审计日志与修订记录核对 |
| KPI-08 | 月度可用性 | ≥ 99.9% | 生产监控 |

## 3. 用户与核心任务

| 角色 | 核心任务 | 主要困难 | 产品响应 |
|---|---|---|---|
| 学习者 | 查含义、对译和发音 | 不知道输入语言或正确拼写 | 自动识别、容错、发音和例句 |
| 翻译人员 | 选用领域正确的规范词 | 同词多义、地区差异 | 领域、来源、地区和用法标注 |
| 专业人员 | 快速理解概念及关联 | 单一译词缺少知识上下文 | 定义、上下位和相关概念 |
| 编辑 | 创建和修订三语词条 | 数据项多、易遗漏 | 多语编辑器、实时质量校验 |
| 审核专家 | 判断概念与译词质量 | 难以看清变更与证据 | 差异对比、来源和审核意见 |
| 数据管理员 | 批量维护和纠错 | 格式不一、重复和关系错误 | 暂存校验、错误报告、可回滚导入 |

## 4. 范围

### 4.1 V1.0 必须交付

- Web 用户端：搜索、结果、详情、语音入口、登录、收藏、历史、反馈。
- UniApp 手机端：搜索、结果、详情、语音、收藏和历史。
- 管理端：概念编辑、审核发布、领域与来源、导入导出、质量报告、日志。
- 服务端：统一身份、版本化 API、术语领域模型、搜索索引、缓存、后台任务和审计。
- 数据：四个一级领域，支持扩展；三语首选词、变体、定义、例句、来源和概念关系。

### 4.2 V1.0 不包含

- 自动生成内容直接发布。
- 复杂知识图谱推理和生成式问答。
- 社区论坛、即时通信和付费计费。
- 未经许可的网页抓取或商业词典复制。
- 全量离线词典包。

## 7. 核心业务规则

1. 概念是多语术语、定义和关系的聚合根。
2. 同一概念、语言和地区最多一个首选术语。
3. 同形词可以对应多个概念，结果必须显示领域与义项差异。
4. 已发布内容只能通过新修订变更。
5. 发布必须经过审核，并保存来源、提交人、审核人、时间和版本。
6. 上下位与整体部分关系禁止自指和环路。
7. 数据库是唯一事实来源；搜索、缓存和音频衍生物可重建。
8. 机器生成内容必须标为候选并经过人工审校。

| 审核模式 | 编辑与审核分离，发布者授权 | 工作流和角色权限 |

## 9. 依赖与限制

- 首批术语数据及其许可证尚未提供，现阶段样例仅用于设计与测试结构。
- 语音供应商、部署区域和预算待确认，系统必须通过适配层解耦。
- 搜索准确率依赖领域词表、变体数据和专家构建的黄金查询集。
- 第三方数据只有在授权明确时才能进入正式词库。

## 10. 需求变更规则

需求基线通过后，新增或修改需求必须包含变更原因、影响的需求编号、数据迁移、接口、测试、排期和负责人。Must 范围变更需要产品、术语和技术负责人共同批准。
